# 风险检查清单

## 版权风险

- [ ] 是否没有上传任何赛事视频？
- [ ] 是否没有下载、缓存、转码赛事视频？
- [ ] 是否没有未经允许 iframe 嵌入视频？
- [ ] 是否所有链接都指向官方公开页面？

## 文案风险

- [ ] 是否没有使用“官方授权”？
- [ ] 是否没有使用“央视合作”？
- [ ] 是否没有暗示自己是赛事官方入口？
- [ ] 是否明确声明第三方工具属性？

## 剧透风险

- [ ] 页面是否没有比分？
- [ ] 页面是否没有胜负信息？
- [ ] 页面是否没有赛后新闻标题？
- [ ] 页面是否没有暗示性词汇？
- [ ] 缩略图是否不会泄露比分？

## 技术风险

- [ ] 插件是否不会破坏视频播放器？
- [ ] 自动跳过失败时是否不影响播放？
- [ ] 页面隐藏规则是否可恢复或可调整？
- [ ] 是否测试了主流浏览器？
