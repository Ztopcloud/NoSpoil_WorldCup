# 3 天上线计划

## 第 1 天

目标：网站能打开，基本页面齐全。

任务：

1. 初始化网站项目。
2. 完成首页结构。
3. 完成比赛列表读取 JSON。
4. 完成插件下载页。
5. 完成安装教程页。
6. 完成免责声明页。

## 第 2 天

目标：插件能本地安装并初步生效。

任务：

1. 完成 Manifest V3 插件。
2. 完成 content script。
3. 完成 CSS 隐藏规则。
4. 测试至少一个官方复播页面。
5. 打包 zip。
6. 放到网站下载目录。

## 第 3 天

目标：发布上线并开始传播。

任务：

1. 检查所有页面文案。
2. 检查无剧透原则。
3. 部署网站。
4. 测试下载链接。
5. 写一篇使用教程。
6. 发布到朋友圈、微信群、知乎、X、小红书等渠道。

## 优先级原则

先保证“能用”，再追求“好看”。

核心体验只有一个：

> 用户在不知道比分的情况下，顺利进入官方复播观看。
