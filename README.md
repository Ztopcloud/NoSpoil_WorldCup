# 时差观赛 / scgs.tv

这是一个面向中国观众的世界杯时差观赛复播导航项目。

## 项目定位

本项目不是直播网站，不上传、不下载、不转播任何比赛视频。

核心定位：

> 时差观赛官方复播导航 + 浏览器本地净屏插件

用户在第二天观看官方复播时，可以尽量避开比分、赛果、评论、推荐标题等剧透信息。

## MVP 功能

1. 网站只展示比赛时间、对阵双方、官方复播入口。
2. 不展示比分、赛果、晋级信息、赛后新闻。
3. 提供浏览器插件下载与安装教程。
4. 插件在用户本地隐藏可能包含剧透的信息。
5. 插件尝试自动跳过片头，避免开场画面出现比分或赛果。

## 推荐技术路线

- 网站：静态站优先，可用 Vite + React 或纯 HTML/CSS/JS。
- 数据：使用 `website/data/matches.json` 或 JSON 文件维护。
- 插件：Chrome Manifest V3 本地加载插件。
- 部署：Cloudflare Pages / Vercel / Netlify。

## 关键原则

- 不搬运视频。
- 不嵌入未经授权的视频。
- 不伪装官方。
- 不使用“官方授权”“央视插件”等误导性表述。
- 网站文案统一使用“官方公开复播页面”“第三方本地辅助工具”等表述。
