# 用户使用指南

## 使用流程

1. 先安装“时差观赛助手”浏览器插件。
2. 打开“时差观赛”网站：`scgs.tv`。
3. 在比赛列表中选择你想看的比赛。
4. 网站只显示时间和对阵双方，不显示比分和赛果。
5. 点击“无剧透观看”，进入官方公开复播页面。
6. 插件会自动隐藏可能剧透的标题、评论、推荐等内容。
7. 直接观看比赛复播。

## 推荐使用习惯

为了避免被其他平台剧透，建议：

- 观看前不要打开新闻 App。
- 不要搜索球队名。
- 不要看社交平台热搜。
- 直接从本站进入复播页面。

## 如果插件没有生效

可以尝试：

1. 刷新页面。
2. 确认插件已启用。
3. 确认当前页面是支持的官方复播页面。
4. 手动避开评论区和推荐区。
