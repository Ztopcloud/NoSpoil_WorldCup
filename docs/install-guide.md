# 插件安装教程

## 适用浏览器

推荐使用桌面版 Chrome 浏览器，或其他兼容 Chrome 扩展的浏览器。

## 安装步骤

1. 下载插件压缩包：`scgs-tv-extension.zip`。
2. 将压缩包解压到一个固定文件夹。
3. 打开 Chrome 浏览器。
4. 在地址栏输入：

```text
chrome://extensions/
```

5. 打开右上角“开发者模式”。
6. 点击“加载已解压的扩展程序”。
7. 选择刚才解压出来的插件文件夹。
8. 安装完成后，打开官方复播页面。
9. 页面顶部出现“无剧透模式已开启”即表示插件生效。

## 注意事项

- 不要删除解压后的插件文件夹，否则浏览器可能无法继续加载插件。
- 如果插件没有生效，请刷新复播页面。
- 如果自动跳过前段失败，可以手动拖动播放器进度条。
