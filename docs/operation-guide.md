# 运营维护指南

## 每日维护流程

1. 前一天或当天找到官方公开复播链接。
2. 更新比赛数据文件。
3. 只填写以下信息：
   - 日期
   - 北京时间
   - 主队
   - 客队
   - 官方复播链接
   - 建议跳过秒数
4. 不填写比分、赛果、晋级、新闻标题。
5. 打开网站检查列表是否正常。
6. 点击每个链接测试是否能进入官方复播页面。
7. 打开插件测试是否隐藏主要剧透区域。

## 数据检查清单

发布前检查：

- [ ] 页面没有比分。
- [ ] 页面没有胜负字样。
- [ ] 页面没有“爆冷”“大胜”“绝杀”等暗示词。
- [ ] 缩略图没有比分，如果有则不展示缩略图。
- [ ] 链接指向官方公开页面。
- [ ] 插件下载链接可用。

## 链接命名建议

按钮文案建议使用：

- 无剧透观看
- 前往官方复播
- 打开复播页面

避免使用：

- 看比赛结果
- 精彩集锦
- 赛后回放
- 谁赢了
