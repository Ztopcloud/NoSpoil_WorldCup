Extension Guide

安装时差观赛助手

轻量的浏览器扩展、Windows 客户端与 Android 应用，帮你自动隐藏复播页的比分、标题和评论区——像看直播一样看回放。

Windows

Windows 客户端安装教程

下载压缩包，完整解压后运行客户端。它会优先打开专用 Edge 窗口，并临时加载内置净屏助手。

下载 Windows 版 版本：v0.2.13
  1. 01

    下载压缩包

    将 nospoil-worldcup-windows.zip 保存到电脑上容易找到的位置。

  2. 02

    完整解压文件夹

    右键压缩包选择全部解压，保留解压后的整个文件夹，不要只单独拖出 exe 文件。

  3. 03

    运行客户端

    打开解压后的文件夹，双击「时差观赛.exe」。若 Windows 提示未知发布者，选择更多信息后继续运行。

  4. 04

    从专用窗口观看

    程序会打开 scgs.tv。后续看复播时从这个窗口进入比赛页面即可。

Windows 版依赖本机 Microsoft Edge。若系统未检测到 Edge，会改用默认浏览器打开页面，此时不会自动加载内置净屏助手。

Browsers

浏览器插件教程

Recommended 版本：v0.2.13

Chrome

下载 Chrome 版

最直接的安装路径，打开 chrome://extensions/ 后启用开发者模式并加载解压后的文件夹。

Chromium 版本：v0.2.13

Edge

下载 Edge 版

可在 edge://extensions/ 中加载已解压的扩展程序，整体步骤与 Chrome 基本一致。

Chromium 版本：v0.2.13

360 浏览器

下载 360 版

桌面版通常支持开发者模式扩展安装，入口位置可能在扩展中心或管理页内。

Chromium 版本：v0.2.13

QQ 浏览器

下载 QQ 版

新版桌面端一般可兼容 Chrome 扩展，进入扩展管理页后加载已解压文件夹即可。

Check support 版本：v0.2.13

UC 浏览器

下载 UC 兼容版

是否支持本地开发者模式扩展，取决于桌面版本。建议优先使用 Chrome 或 Edge，稳定性更高。

Separate build 版本：v0.2.13

Firefox

下载 Firefox 版

火狐扩展体系不同，使用单独打包版本。长期发布时建议继续走 Firefox 扩展签名流程。

  1. 01

    先在上方浏览器卡片里下载对应版本压缩包，再把它解压到一个固定文件夹，后续浏览器会一直从这个文件夹读取助手文件。

  2. 02

    打开你常用浏览器的扩展管理页。Chrome 可用 chrome://extensions/，Edge 可用 edge://extensions/，其他 Chromium 浏览器通常也有对应的扩展管理入口。

  3. 03

    打开"开发者模式"，点击"加载已解压的扩展程序"，选择刚才解压出来的助手文件夹。不要在安装后删除或移动这个文件夹。

  4. 04

    从本站比赛入口打开支持的官方公开复播页面。看到"时差观赛模式已开启"提示，或页面里的标题、评论、推荐等剧透区域被隐藏时，就表示助手已经生效。

注意：Chrome、Edge、360、QQ 和 UC 使用 Chromium 兼容包；Firefox 使用单独版本。助手只在本地浏览器里净屏，不会接管播放。

Local assistant

只做本地净屏，不接管播放

支持平台

桌面端支持 Chrome/Edge/Firefox/360/QQ/UC 等浏览器插件安装；手机端提供 Android APK 安装包，覆盖电脑和手机两种观赛场景。

本地运行 / 隐私安全

无论是浏览器插件还是手机 App，都只在本地运行，不上传浏览记录、不收集个人信息，也不需要注册登录。

失败不影响观看

浏览器插件和手机 App 都会按视频时长尝试跳过前段，但如果页面限制了进度跳转，视频仍会照常播放，你可以手动调整进度继续观看。

Before replay

打开复播前，先确认助手处于启用状态

如果没有生效，请刷新复播页面，或回到扩展管理页重新检查开关和文件夹加载状态。安卓用户请确保已安装并打开 App。
